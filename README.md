# Personal Portfolio Website

## Overview

This repository contains my personal portfolio website developed using HTML, CSS, and JavaScript. The website presents my academic background, skills, projects, CV, and contact information.

## Pages

- Home
- CV
- Projects
- Contact

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## Features

- Multi-page website structure
- Semantic HTML elements
- Responsive styling
- External CSS stylesheet
- JavaScript form validation
- Interactive project descriptions
- Page load message using JavaScript

- How to build and structure a multi-page website
- How to apply semantic HTML
- How to style pages using external CSS
- How to add interactivity using JavaScript
- How to deploy a website using GitHub Pages
